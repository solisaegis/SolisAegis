# Machine-Readable Companions

This directory contains the exact available machine-readable companions mirrored with the Final v1.0 core:

- Document 3 Master Question Registry CSV, JSON, JSON Schema, and validation report.
- Document 13 unresolved/non-identification register JSON and CSV.
- Document 14 synthesis/dependency atlas JSON and three CSV views.

These companions are descriptive research records. They are not operational control protocols, safety classifiers, governance mechanisms, or authorization systems. Repository identifiers and later public references belong in mutable wrappers rather than in locked artifacts.
