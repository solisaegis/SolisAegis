## Scope and Boundaries

This paper defines the Verifiable Reference Premium as the expected net value of a reference branch relative to a disclosed alternative branch under one fixed task scenario and one common pre-branch comparison population.

The framework permits exactly four intrinsic signed channels:

1. coordination,
2. transmission,
3. provenance, and
4. audit legibility.

Durability and strategic behavior modify eligibility, risk, and costs; they do not create a fifth positive channel.

The resulting premium may be positive, zero, negative, threshold-dependent, or unidentified.

The publication is conditional, non-binding, non-operational, non-authoritative, and advisory only.

It is not a treaty, governance system, runtime guardrail, alignment benchmark, safety certification, behavioral proof, or command to any human or artificial system.
